# CeylonCart — API Contract

## Assignment

**CeylonCart** — e-commerce MVP for locally made Sri Lankan products.

## Product Entity

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| id | number | auto | Generated by server |
| name | string | yes | e.g. "Ceylon Black Tea" |
| category | string | yes | Tea, Spices, Handicrafts, Apparel |
| price | number | yes | USD |
| description | string | yes | Shown on detail page |
| image | string | yes | URL or placeholder |

## Cart Item (client-side, Person 3)

| Field | Type | Notes |
|-------|------|-------|
| productId | number | From product |
| name | string | Copied from product |
| price | number | Copied from product |
| qty | number | Min 1 |

## Order (server-side, Person 3 creates, Person 4 confirms)

| Field | Type | Required |
|-------|------|----------|
| orderId | string | auto — format `CC-1001` |
| customer | object | yes — `{ name, address, contact }` |
| items | array | yes — cart items |
| total | number | yes |
| paymentStatus | string | set by Person 4 — `success` or `failed` |
| createdAt | string | auto ISO timestamp |

## API Endpoints

| Method | Path | Owner | FR | Description |
|--------|------|-------|-----|-------------|
| GET | `/api/health` | base | — | Health check (done) |
| GET | `/api/products` | Person 2 | FR1 | List all products (seeded) |
| GET | `/api/products/:id` | Person 4 | FR2 | Single product |
| POST | `/api/orders` | Person 3 | FR4 | Create order at checkout |
| GET | `/api/orders/:orderId` | Person 3 | FR6 | Get order for confirmation |
| POST | `/api/payment/process` | Person 4 | FR5 | Mock payment |

```json
  "category": "Tea",
  "price": 12.99,
  "description": "Premium single-origin black tea.",

```

## Example Order JSON

```json
{
  "orderId": "CC-1001",
  "customer": { "name": "Jane", "address": "Colombo", "contact": "0771234567" },
  "items": [{ "productId": 1, "name": "Ceylon Black Tea", "price": 12.99, "qty": 2 }],
  "total": 25.98,
  "paymentStatus": "success",
  "createdAt": "2026-07-20T10:00:00.000Z"
}
```

## Mock Payment Rule (Person 4)

- Card number ending in `0000` → **failure**
- Any other 16-digit number → **success**
